# GW Vendor Onboarding

Odoo 18 demo module: Vendor onboarding 4-step form using Owl.js.

## Installation
1. Place `gw_vendor_onboarding` in your Odoo addons directory.
2. Update apps list and install the module.
3. Navigate to `/vendor_onboarding_page` on your website.

## Features
- 4-step Owl.js onboarding form
- State persistence across steps
- Basic structure for product upload, business terms, compliance & billing
- Demo JSON submission endpoint
